# Sumber pihak ketiga

## Dataset dan deskripsi MetroPT-3

Davari, N., Veloso, B., Ribeiro, R., dan Gama, J. (2021). MetroPT-3 Dataset. UCI Machine Learning Repository. DOI: https://doi.org/10.24432/C5VW3R

Sumber: https://archive.ics.uci.edu/dataset/791/metropt+3+dataset  
Lisensi: CC BY 4.0, https://creativecommons.org/licenses/by/4.0/

Lisensi kode pada root repository tidak menggantikan lisensi dataset. `data/sample_sensor_1000.csv` merupakan ekstraksi 1.000 baris pertama; formatting CSV ditulis ulang. `data/Data_Description_Metro.pdf` disalin dari arsip sumber. Tabel/grafik eksperimen dihasilkan melalui pengolahan dataset yang dijelaskan pada notebook.

## Pustaka

Python, NumPy, pandas, SciPy, scikit-learn, joblib, Matplotlib, seaborn, IPython, threadpoolctl, lxml dan Pillow digunakan melalui instalasi dependensi; source pustaka tidak disalin ke repository ini. Versi dicatat pada file lingkungan dan requirements.
